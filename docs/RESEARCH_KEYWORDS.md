# IACF Research Keywords & Presentation Guide

## Core Research Terms

### Primary Keywords
1. **Behavior-Aware Communication**
   - Data-centric scheduling paradigm
   - Pattern-based priority assignment
   - Anomaly-driven transmission

2. **Dynamic Priority Scheduling**
   - Real-time priority calculation
   - Deadline-aware packet ordering
   - Age-based starvation prevention

3. **Adaptive Baud Optimization**
   - Urgency-driven speed selection
   - 5-level bandwidth adaptation
   - Power-aware transmission

4. **Intelligent UART Framework**
   - Decision-engine architecture
   - Multi-layer communication stack
   - Behavior analysis foundation

5. **Real-Time Communication Adaptation**
   - Sub-microsecond latency decisions
   - Dynamic reconfiguration
   - Responsive system behavior
